# Clarity Judge screenshot protocol

Use a clean browser profile with no saved key and a deployment or local server with no server key. Select one built-in synthetic writing example and run in visibly labeled demo mode. Do not submit private drafts or make paid provider calls merely to capture the interface.

Useful captures are the editor with selected checks, the verdict panel with evidence and uncertainty visible, and a narrow-screen layout. Keep demo labels and low-confidence/Needs review states visible. Do not edit a displayed probability to manufacture an impressive result.

Record the source commit, local/preview/production environment, route, viewport, scale, theme, example, and checks performed. Verify keyboard navigation separately. Review screenshots and exports for private writing and credentials before publishing.

The SVG card is an editorial graphic. This documentation change does not claim new application screenshots or a deployed visual pass. Follow the [shared evidence protocol](https://github.com/TypeSafeAI/.github/blob/main/docs/discovery/SCREENSHOTS.md).
